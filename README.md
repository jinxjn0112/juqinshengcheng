# 剧情灵感工坊

一个面向 SillyTavern（酒馆）的纯前端第三方扩展。它使用酒馆当前选中的模型，在当前角色卡、世界书、作者注释和聊天记录的上下文中生成剧情灵感，不需要单独配置 API。

## 功能

- **剧情走向**：从当前节点生成多个有动机、有后果的分支。
- **新剧情**：提供能直接接入当前故事的场景、节拍与开场文字。
- **番外**：支持前传、间章、同期另一视角与后日谈。
- **大纲**：按 3、5 或 7 章规划目标、冲突升级、伏笔和章末钩子。
- **伏笔工坊**：区分已有线索与新伏笔候选，避免把新设定伪装成旧线索。
- **灵感盲盒**：混合生成事件、选择、秘密、环境变化与小转折。
- 三档创意幅度、四档时间范围，以及人物一致性、避免重复、伏笔优先、玩家自主权等选项。
- 结果可复制、填入酒馆输入框、换一批或继续细化。
- 每个聊天单独保存最多 12 条灵感记录；可在面板中关闭自动保存。
- 适配桌面和手机界面，无第三方网络依赖。

## 安装

1. 解压下载的 ZIP。
2. 将完整文件夹 `SillyTavern-PlotWeaver` 放进：

   `SillyTavern/data/<你的用户名称>/extensions/`

3. 重启 SillyTavern，或在浏览器中强制刷新页面。
4. 打开任意角色聊天，点击输入框旁的扩展菜单（魔杖图标），选择“剧情灵感工坊”。

如果你使用的是较老的 SillyTavern，第三方扩展目录可能仍是：

`SillyTavern/public/scripts/extensions/third-party/`

## 使用提示

- 先让剧情进行几轮，模型能得到更明确的当前目标与未完成事件。
- “大胆”会提高结构变化幅度，但提示词仍要求保持人物设定与连续性。
- “这一次的额外要求”只作用于当前生成；“长期偏好”会保存在扩展设置中。
- “填入输入框”不会自动发送，你可以先删改再决定是否发送。
- 生成实际使用的模型、API 和额度均来自你当前的 SillyTavern 配置。

## 隐私与安全

扩展本身不连接外部服务器，也不上传或收集数据。上下文会按照 SillyTavern 当前 API 配置发送给你已经选择的模型。灵感历史存放在当前聊天的元数据中。

内置提示词要求模型避免露骨性内容、血腥细节、自伤描写以及现实危险行为指导，并保留玩家角色的选择空间。

## 兼容性

- 最低 SillyTavern 版本：1.13.0
- 推荐使用较新的稳定版 SillyTavern
- 已按当前扩展清单格式和 `generateQuietPrompt({ quietPrompt })` 接口编写

## 卸载

关闭 SillyTavern 后删除 `SillyTavern-PlotWeaver` 文件夹，再重新启动即可。删除扩展不会删除原有聊天内容；已经写入聊天元数据的灵感记录不会显示，但可能仍保留在聊天文件中。
